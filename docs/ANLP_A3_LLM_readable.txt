Implementation Tasks

Part A Transformers are currently one of the most widely used
architectures, especially for language modelling. However, its quadratic
time complexity has motivated the development of alternative
architectures that aim to achieve comparable performance while scaling
linearly with sequence length. Two of the notable ones are Mamba and
DeltaNet.

You have been given a dataset consisting of plaintext sequences
(cleaned.jsonl) and their corresponding encrypted sequences
(cipher.jsonl). The dataset can be found here. The password for the same
is mentioned in the assignment announcement.

In this section, we will explore how well these architectures can learn
a cipher function, whether com­ bining them offers any advantage over
using them individually, and how well do they compare against a
Transformer.

Your mission, should you choose to accept it (you don’t have a choice),
is to build models that learn the underlying cipher function and decrypt
previously unseen encrypted sequences. The train-validation- test split
has already been provided.

You are required to implement the following models: 1. Transformer (you
may reuse your previous implementations) 2. Mamba (as described in the
paper) 3. DeltaNet (as described in the paper) 4. Mamba-DeltaNet Hybrid:

Part B A news propagation graph is a network model that maps how a news
story or post spreads across social media.

You will use the GossipCop subset of UPFD. In this dataset, each sample
is a news propagation graph where node 0 is the source news post, the
remaining nodes are Twitter users who interacted with it. The edges
connect these nodes to map out the flow of a tweet between the users.
Use PyG’s loader to download and cache the data. The
train-validation-test split is fixed at 20%-10%-70%; do not change or
re-split it.

Architecture Comparison Train and evaluate the following models using
bert features (already given in the dataset), with 5 random seeds
each: 1. Root-Only MLP: Use only node 0 (the source post) for
classification, discarding all retweeter nodes and edges. This serves as
your text-only baseline. 2. GCN 3. GraphSAGE 4. GAT 5. Bi-GCN

Compare these models to determine whether the propagation graph improves
classification over the source text alone, and which architecture works
best.
